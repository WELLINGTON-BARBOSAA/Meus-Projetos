# 💻 Portfólio de Projetos em Python

O repositório, tem meus primeiros projetos desenvolvidos em Python durante minha jornada de aprendizado em programação que comecei em 2025. O objetivo principal é praticar lógica, entrada e saída de dados, condicionais, funções e organização de código.

---

## 📚 Projetos

📚 Projetos

# Calculadora de Pace

Projeto que calcula o ritmo médio por quilômetro a partir do tempo total e da distância percorrida. Trabalha operações matemáticas, conversões de tempo e formatação de saída.

# Ficha Médica

Aplicação de cadastro simples de paciente com exibição organizada das informações. Focado em manipulação de strings e organização de dados.

# Calculadora

Calculadora de operações matemáticas básicas com escolha do usuário. Explora operadores aritméticos e estruturas condicionais.

# Contador de Palavras

Programa que analisa um texto digitado e informa a quantidade de palavras. Desenvolve manipulação de strings e processamento de entrada.

# Notas de Alunos

Sistema que calcula média de notas e determina a situação do aluno (aprovado, recuperação ou reprovado). Trabalha lógica condicional e tomada de decisão.

# Calculadora de Salário Mensal

Ferramenta que estima ganhos mensais com base em valores informados pelo usuário. Aplica matemática prática e tratamento de entrada de dados.

# Calculadora conversora de idade de cachorro para humano

Projeto desenvolvido em Python para calcular a idade humana equivalente de um cachorro, considerando seu peso, porte e idade.

## 🧠 Objetivo do Repositório

Este repositório faz parte do meu processo de evolução na programação. Cada projeto foi desenvolvido para reforçar fundamentos importantes como:

* Lógica de programação
* Estruturas condicionais
* Entrada e saída de dados
* Organização do código
* Pensamento computacional

O objetivo é manter cada projeto como um registro visível da minha evolução técnica.
